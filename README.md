# Hackathon Monsoons Team

This is the GitHub repository for the hackathon monsoons team! 

## Suggested workflow
- make a branch with either your name or something specific you want to work on then the day 
- if you would like, make a folder about the thing you're doing (e.g. `mkdir mse_budget`)
- start coding on that branch
- regularly commit changes and push your commits to your branch
- if you would like, open a pull request at the end of each day so you can share what you've done with the rest of the team more easily
- fran or someone else will merge it to the main branch!

### Planned topics to work on
- identifying monsoon onset
- identifying monsoon demise/retreat
- calculating various budgets
  - DSE & MSE
  - moisture
  - momentum
  - circulation & vorticity
  - angular momentum
- teleconnections between monsoons and other seasonal/subseasonal variations
- relationship between onset & planetary overturning circulations
- ITCZ locations and energetic constraints on monsoon extent
- heat lows and their relation to monsoon onset
- mediation of monsoon onset by multiscale processes including
  - MCSs
  - tropical-extratropical cloud bands
  - small-scale convection
- interscale energy transfer during monsoon season
- Rossby waves and their role in mediating southern hemisphere monsoon precipitation
- interactions with equatorial waves
